# aws

Module for aws-related tooling and shell helpers.

## Files

- bash.sh: shell helpers for aws.
- install.sh: install aws through the central installer runtime.
- uninstall.sh: uninstall aws through the central installer runtime.
- install.windows.ps1: PowerShell wrapper for aws installation on Windows.

## Aliases

Accepted alias names: awscli

## Usage

From repo root:

```bash
bash ./tools.install.sh aws
```

```bash
bash ./tools.uninstall.sh aws
```

PowerShell (Windows):

```powershell
pwsh ./aws/install.windows.ps1
```
