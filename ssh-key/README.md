# ssh-key

Module for ssh-key-related tooling and shell helpers.

## Files

- install.sh: install ssh-key through the central installer runtime.
- uninstall.sh: uninstall ssh-key through the central installer runtime.
- install.windows.ps1: PowerShell wrapper for ssh-key installation on Windows.

## Usage

From repo root:

```bash
bash ./tools.install.sh ssh-key
```

```bash
bash ./tools.uninstall.sh ssh-key
```

PowerShell (Windows):

```powershell
pwsh ./ssh-key/install.windows.ps1
```
