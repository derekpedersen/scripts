# node

Module for node-related tooling and shell helpers.

## Files

- install.sh: install node through the central installer runtime.
- uninstall.sh: uninstall node through the central installer runtime.
- install.windows.ps1: PowerShell wrapper for node installation on Windows.

## Usage

From repo root:

```bash
bash ./tools.install.sh node
```

```bash
bash ./tools.uninstall.sh node
```

PowerShell (Windows):

```powershell
pwsh ./node/install.windows.ps1
```
